Security & Runtime

兼顾单机敏捷与企业隔离的工程底座

零第三方 JavaScript 运行时依赖，面向长期合规留存与多团队协作而构建。

多租户隔离与 RBAC

工作区严格数据隔离，OWNER 与 MEMBER 职责分离；支持邀请链接加入、TOTP 双因素认证、会话管理与停用即时撤销。

SSRF 防护与来源治理

拒绝内网、回环与云元数据地址，执行 DNS 多 IP 校验与重定向复查；支持域名白名单、15 分钟限流与连续失败自动熔断。

保留政策清除与安全导出

支持不可逆清除证据原文并自动脱敏草稿引用；业务全量 CSV 导出内置公式注入防护并完整保留只追加审计日志。

双引擎持久化与外部 Worker

支持本地 SQLite 与零第三方驱动 PostgreSQL 实时运行时；可选独立后台 Worker 执行租约队列、定时重查与 KMS 加密连接器。
